macOS Installation & Gatekeeper Notice Resolution

Installation · macOS Apple Silicon & Intel
Installation

ArmoryVault distributes universal native installers for Apple Silicon (arm64.dmg) and Intel Macs (.dmg). Because ArmoryVault is an open-source community tool built without costly enterprise certificate fees, macOS Gatekeeper may present an "unidentified developer" notice upon first launch.

Step-by-Step Installation:

  1. Download the appropriate .dmg for your Mac architecture from the Downloads section.
  2. Double-click the disk image and drag ArmoryVault.app directly into your Applications folder.
  3. Option A (GUI): In Finder, navigate to Applications, right-click (or Control-click) ArmoryVault.app, click Open, and confirm Open in the system prompt.
  4. Option B (Terminal Fix): Open Terminal and run the quarantine clearing command:
xattr -cr /Applications/ArmoryVault.app
Tip: Once executed once, macOS remembers the approval and launches ArmoryVault instantaneously on subsequent boots.

Windows 11 / 10 Installation & SmartScreen Guide

Installation · Windows 64-bit EXE
Windows

The official Windows installer packages a fully self-contained runtime with automatic desktop shortcut integration.

Installation Instructions:

  1. Download ArmoryVault-Setup-3.0.0-Electron.exe.
  2. Double-click the setup file to launch the installation wizard.
  3. If Microsoft Defender SmartScreen displays "Windows protected your PC":
    • Click More info.
    • Click Run anyway.
  4. When prompted by Windows Defender Firewall for network permissions, check Private networks to allow the Mobile Companion app to discover the desktop over local Wi-Fi.

Linux Universal AppImage Execution

Installation · Ubuntu, Fedora, Debian, Arch
Linux

The AppImage is a portable binary containing all dependencies, compatible across modern Linux distributions (Ubuntu, Fedora, Debian, Linux Mint, Arch, etc.).

Running the AppImage:

chmod +x ArmoryVault-3.0.0-Electron.AppImage && ./ArmoryVault-3.0.0-Electron.AppImage

You may also move the AppImage to ~/.local/bin/ or register it with AppImageLauncher for automatic desktop launcher integration.

Zero-Cloud Local Wi-Fi Pairing Walkthrough

Pairing · Peer-to-Peer LAN Synchronization
P2P Sync

ArmoryVault uses an innovative Zero-Cloud Local Sync Protocol. Your firearm and ammo records never touch an external cloud server; data synchronizes strictly inside your own home router's local subnet.

How to Pair Desktop & Mobile:

  1. Connect your computer and smartphone to the same Wi-Fi router or local home network.
  2. In ArmoryVault Desktop, click the Companion Sync tab. The desktop displays a secure QR pairing code containing an ephemeral handshake token and your local IP address.
  3. On your phone, open ArmoryVault Companion and tap Pair Vault (or the camera scan button).
  4. Aim your camera at the desktop screen to scan the QR code.
  5. The devices establish an encrypted connection over your local LAN. Your firearms, ammo inventory, and storage locations will synchronize in seconds.

Firewall & Local Network Troubleshooting

Troubleshooting · Ports, Subnets & Firewalls
Network

If your mobile device cannot reach the desktop after scanning the QR code, review the common network checkpoints below:

  • Same Subnet Check: Ensure your phone is connected to your primary home Wi-Fi and not on cellular 5G/LTE or a separate "Guest" Wi-Fi network.
  • Router AP Client Isolation: Some routers have "Client Isolation" enabled on guest Wi-Fi, preventing local devices from talking to each other. Connect both to the standard 2.4GHz or 5GHz home SSID.
  • Windows Defender Firewall: Search for "Allow an app through Windows Firewall" in Windows Settings, locate ArmoryVault, and verify that the Private checkbox is checked.
  • macOS Local Network Prompt: Under macOS System Settings -> Privacy & Security -> Local Network, ensure ArmoryVault is enabled.

Shotgun Shell Specifications & Telemetry

Shotguns

Shotgun ammunition contains unique specifications that rifle and pistol rounds lack. ArmoryVault provides dedicated fields for:

  • Gauge Classification: 10ga, 12ga, 16ga, 20ga, 28ga, and .410 bore.
  • Shell Length: 1 3/4" (Mini-shell), 2 3/4" (Standard), 3" (Magnum), 3 1/2" (Super Magnum).

Vault Security, Recovery Keys & Cold Backups

Security · AES-256 Encryption, USB Backups & Migration
Security

ArmoryVault encrypts your local database with AES-256-GCM using high-iteration PBKDF2 key derivation. Because there are no cloud accounts or server recovery backdoors, following backup best practices is essential.

Best Practices for Cold Storage & Migration:

  1. Record Your 24-Word Recovery Key: Upon initial vault setup, write down your mnemonic recovery phrase on physical paper and store it in your fireproof safe.
  2. Export Encrypted Backups: In Settings -> Backup Vault, click Export Encrypted Database. Save the resulting encrypted .avdb file to an external USB flash drive or cold storage device.
  3. Migrating to a New Computer: Install ArmoryVault on your new machine, click Restore from Backup, select your .avdb file, enter your master password, and your entire collection is immediately restored.
